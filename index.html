accessctl

Python · YAML · pytest · GitHub Actions
  • One command grants a new hire everything their role entitles them to; one command shuts a leaver down in the safe order (disable sign-in → revoke sessions → transfer ownership → strip access → optionally delete); one command reconciles the HR roster against every system and reports who has access they shouldn't, ranked by severity.

site-health-monitor

Python · GitHub Actions · GitHub Pages
  • Hourly checks for a list of sites: HTTP status and latency, TLS expiry, SPF / DKIM / DMARC correctness, broken links, and WordPress login health. Alerts by email or Slack only when a site's status changes, so one message per incident and one on recovery.
  • Runs entirely on free GitHub Actions; history is committed to the repo and rendered as a static status page on GitHub Pages, so there is no server and no database.
  • All network access is behind small seams, so 24 tests run offline in under a second.
Source and README on GitHub · Live status page

crm-migration-toolkit

Python · pandas · rapidfuzz
  • Maps source columns to canonical fields, normalises names, emails and phones (E.164), validates rows, and de-duplicates in two stages: exact by email, then fuzzy within blocking keys with per-key thresholds, so a shared phone is trusted more than a shared email domain.
  • Nothing is dropped silently: rejects carry a reason, merges carry a match type and score, and every changed field is written to a before/after audit trail with a summary report.
  • Rules live in YAML so a new migration means editing config, not code. Tests check that clean + rejected + merged always equals input.
Source and README on GitHub
